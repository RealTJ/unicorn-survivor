# Dev Diary – Day 1

Mostly spend setting up everything. Poked around in BroMetals source code and tried to find out how it works.

Big question mark that I had was how the connection between game and animation in shader would work.

For the rest I had an Idea how to do it and looked through old code of mine and checked what was there.

I found an old abondend project (I swear that I will work on it in the future) and copied some of the mapping code. It uses UInt8Array to store map data and copied some code over.

Took a long time to figure out how the world should work and settled on the world moving with the character.

Started programming and struggled with if I should use self build vector class and how it would look like [^positive-vectors]. Looked up some stuff about the Uint8Array and what the byte order is supposed to mean [^byte-order].
