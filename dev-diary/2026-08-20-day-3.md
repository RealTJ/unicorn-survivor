# Dev Diary – Day 3

This was the most productive of days regarding code to make the game tick. I kinda got stuck the last day and started first by exporting all the AI Chats over the last days to keep record of what I looked up.[^export-ai-chats]
Since I was using this as a learning exercise, I had to do an actual part which I didn't like - keep track of what I did. 

I had the idea that I should start checking early (now), if I can keep the magical limit of 13kb[^js13k-rules]. Since I had no idea how much 13kb is and what the limits actually are. I consulted the AI and copied over the build script, but I lost the conversation where I did that.

Since I got stuck and had no idea how to build what I envisioned, I started querying the AI heavily[^game-world-strategies] in one of the biggest chats to date. I asked how I should manage my world and whether I should put all game state into one big Uint32Array or keep separate layers of Uint8Array for different game objects.
The game map should be huge, and the AI advised me to make a game chunked. Sounded a bit pre-mature optimization to me, but since I want to copy states to shaders later and might not need all game data, keeping it separate makes it easier down the line.

This was a huge learning experience for me, and I was lost multiple times about how to achieve it. 

So I got to work and also switched some functional factories against classes[^js-classes], since the code is a bit terser.
