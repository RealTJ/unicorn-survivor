# Dev Diary – Day 5 – Integrating Brometal

First I started out by integrating brometal. I looked at the documentation for brometal js13k[^brometal-js13k] and noticed that the build process was unusual. 
I queried the AI[^brometal-integrating], but it was less than helpful. It was clear from the documentation that the js13k was compiling it different than normal. 
Since I checked out the source code for brometal in the first day I did a quick lookup and confirmed this was the case. It helped me to structure the build process though.
What I do now is the following:
1. Compile Brometal to `dist/`
2. Compile with Vite to `build/`
3. Zip everything up

There were quite the challenges. The first was that BroMetal hardcoded the `dist/` folder, so I couldn't use this as my target anymore. Since `vite` is more flexible, I changed it to `build/` accordingly and queried the AI how to include them.
This was quite simple as I used the `dist/` folder as a public directory (meaning that the BroMetal always needs to come before vite). This allowed me to directly integrate them like this: 

```html
<script src="/brometal.js"></script>
<script src="/shaders.js"></script>
```

Next up was the example that BroMetal used. I copied it over from the AI Transcript to just get it running, but now we need to refer to globals. I double checked if the `brometal.js` contained the actual runtime and wrote a small typescript definition in `/render/brometal.d.ts`, since I also needed the shaders typed (and they were generated dynamically), I let the AI write a small script to get the shaders definition going. 
This looks a bit cursed, but worked so I felt it was sufficient.
